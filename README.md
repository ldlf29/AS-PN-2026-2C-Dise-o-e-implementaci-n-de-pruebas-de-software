# Proyecto final - Cypress BookDB

Automatización de casos de prueba de Front y API sobre https://app.bookdb.online con Cypress, Page Object Model y comandos personalizados.

## Instalación

```
npm install
```

## Ejecución

```
npx cypress open
```

O por consola:

```
npx cypress run
```
